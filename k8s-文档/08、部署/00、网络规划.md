192.168.10.250 itdachang.com


192.168.10.250是nginx负载均衡器【负载均衡ingress】的地址


ingress TLS证书生成：也可自行申请合法证书


```sh
mkdir -p /root/crt/itdachang
cd /root/crt/itdachang
openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout tls.key -out tls.crt -subj "/CN=*.itdachang.com/O=*.itdachang.com"
```

```sh
#创建 secret
kubectl create secret tls itdachang.com --key tls.key --cert tls.crt
```


集群对外默认全局ingress

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: itdachang.com
  namespace: default
spec:
  defaultBackend:
    service:
      name: nginx-svc
      port:
        number: 80
  tls:
  - hosts:
    - itdachang.com
    - "*.itdachang.com"
    secretName: itdachang.com
```



以后每个东西，配置自己的**ingress-rule规则**即可。总规则在default名称空间已经完成




# ingress示例：rook-ceph-mgr-dashboard

hosts: 192.168.10.250 rook.itdachang.com

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  annotations:
    kubernetes.io/ingress.class: nginx
    nginx.ingress.kubernetes.io/backend-protocol: HTTPS
    nginx.ingress.kubernetes.io/server-snippet: |
      proxy_ssl_verify off;
  generation: 1
  name: ceph-rook-dash
  namespace: rook-ceph
spec:
  rules:
  - host: rook.itdachang.com
    http:
      paths:
      - backend:
          service:
            name: rook-ceph-mgr-dashboard
            port:
              number: 8443
        path: /
        pathType: Prefix
```





# rook访问：mgr是高可用模式

如果mgr是高可用模式【多个实例】，需要创建额外的service

```yaml
vi mgr-server.yaml
apiVersion: v1
kind: Service
metadata:
  labels:
    app: rook-ceph-mgr
    ceph_daemon_id: a
    rook_cluster: rook-ceph
  name: rook-ceph-mgr-dashboard-active
  namespace: rook-ceph
spec:
  ports:
  - name: dashboard
    port: 8443
    protocol: TCP
    targetPort: 8443
  selector:  #service选择哪些Pod
    app: rook-ceph-mgr
    ceph_daemon_id: a
    rook_cluster: rook-ceph
  sessionAffinity: None
  type: ClusterIP
```
